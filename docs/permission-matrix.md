# 权限基线

| 操作 | 普通用户 | 服务人员 | 管理员 |
| --- | --- | --- | --- |
| 老人档案列表/详情 | 本人或当前有效授权范围 | 仅任务必需信息 | 受限运营访问并审计 |
| 创建预约 | 当前有效 `can_book` 家庭授权 | 否 | 否 |
| 查看订单 | 创建人/授权范围且当前有效 | 当前有效任务 | 运营权限 |
| 取消/确认/评价/费用确认 | 创建人、已核验老人本人，或指定订单与操作的受控交接受领人；每次均重新检查当前有效授权及对应独立权限 | 否 | 可指定交接并审计，不可冒充用户 |
| 派单/改派/异常协调 | 否 | 否 | 指定运营权限与合法状态 |
| 接单/拒单/开始/提交完成 | 否 | 仅本人当前有效派单 | 否 |
| 人员与服务项目管理 | 否 | 本人可维护接单状态和请假 | 指定管理权限 |
| 线下结算 | 否 | 否 | 指定结算权限并审计 |
| 生活提醒与偏好 | 当前有效 `can_manage_reminder` / `can_manage_family` 授权 | 否 | 否 |
| 站内消息 | 当前有效家庭授权范围 | 当前有效派单范围 | 自身运营消息 |

每个接口同时检查 RBAC、对象归属/授权、业务状态；列表过滤、详情校验、历史通知链接重新校验。授权撤销和账号停用必须在下一次请求生效。

隔离 MySQL 已验证老人本人身份人工核验、家庭争议处理、受控交接、撤权后列表与详情拒绝访问，以及账号停用后旧 Session 被拒绝。真实身份材料的线下核验过程与 SMTP 邮件送达不在当前自动验收证据内；其余角色与异常操作仍需结合页面持续回归。

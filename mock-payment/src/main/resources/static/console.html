填错了怎么办（金额与结算不一致导致结算无法继续）

主系统同步时先比对金额，不一致会直接拒绝，而且不会把交易改成失败，所以这笔结算会卡在「处理中」，必须手工复位：


    

  1. 在本页把出错的那笔交易设为「取消」，点「② 设置交易结果」，让它退出活跃状态。
    2. 

  2. 在主库 eldercare 执行（把 62 换成订单号）：
    
UPDATE payment_attempt SET remote_status='CANCELLED' WHERE settlement_id=(SELECT id FROM settlement WHERE order_id=62);
    
UPDATE settlement SET status='FAILED' WHERE order_id=62;
    3. 

  3. 回主系统刷新结算面板，重新点「发起模拟支付」，用新的尝试标识和正确金额再登记一次。
